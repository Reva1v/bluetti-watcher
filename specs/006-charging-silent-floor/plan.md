# Plan: 006 — «Тихая» зарядка только с 90 %

Формат короткий. Правка одного модуля решений и значений по умолчанию.

## Решения

- `src/config.rs`: значения по умолчанию `light_silent_at = 90`, `silent_at = 90`. Проверка порядка прежняя
  (`turbo_below ≤ standard_at < silent_at`, `turbo_below < light_silent_at ≤ silent_at`).
- `src/decision/charging.rs`:
  - `Why::Floor { soc, below }` (`code` — `floor`, текст «свет есть, заряд {soc} % ниже {below} %: «Тихая» заменена»).
  - в `update`, после правил включения света и порогов и до выдачи цели: если цели нет (`a.want.is_none()`),
    `!a.light_pending`, сеть `On` и подтверждена, `current == Some(Silent)` и `soc < floor`, где
    `floor = min(cfg.light_silent_at, cfg.silent_at)` — цель `Standard` с `Why::Floor`, а `high_water = Some(soc)`,
    чтобы порог `silent_at` сработал снова (FR-003).
  - пауза после выключения, отключение (`seen.outage`) и бэкофф действуют как раньше: правило стоит ниже этих проверок.
  - `manual()` не меняется: ручная запись проходит, правило сработает на следующем принятом показании.
- `src/service.rs`: причина записи по правилу запоминается на цикл (`rule_note`); если правило в том же цикле сменило
  режим, выбранный нажатием, ответ на нажатие говорит «Автоматика вернула режим «…»: причина» вместо «станция
  показывает другой режим».
- Дашборд не меняется.

## Конституция

- I: та же запись из белого списка по включённому правилу. II: только принятые показания и подтверждённая сеть.
  V: чистая логика с тестами. Отступлений нет.

## Тесты

- `decision/charging`: границы 89/90 для правила; «Турбо» и «Стандартная» не трогаются; сеть не подтверждена, сети нет,
  идёт отключение, пауза после выключения, режим неизвестен — записи нет; заряд 15 % даёт «Стандартная»; после правила
  порог 90 % снова ставит «Тихая»; разные пороги в конфиге (`light_silent_at = 75`, `silent_at = 80`) — правило ниже 75;
  отказ записи и повтор; ровно три режима на зарядке 15 → 95 %.
- Существующие тесты 004 с границами 74/75 и 79/80 переводятся на 89/90.
- `service`: ручная «Тихая» при 60 % и сети заменяется на следующем цикле; при `enabled = false` записи нет.
- `config`: новые значения по умолчанию.
